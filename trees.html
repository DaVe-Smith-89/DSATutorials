Conquering hierarchy with non-linear architectures.

Binary Search Tree (BST)

A Tree is a non-linear data structure. A Binary Tree dictates that each node can have at most 2 children (Left and Right). A Binary Search Tree (BST) adds powerful rules to make searching incredibly fast (O(log N)):

  • The Left subtree of a node contains ONLY nodes with keys lesser than the node's key.
  • The Right subtree of a node contains ONLY nodes with keys greater than the node's key.
  • No duplicate nodes are permitted.

Complex Operations: Deletion

Deleting a node in a BST is tricky because it must remain a valid BST after removal. There are 3 cases:

  1. Leaf Node: Simply delete it and set the parent's pointer to NULL.
  2. Node with 1 Child: Bypass the node by linking its parent directly to its single child.
  3. Node with 2 Children: Find the maximum value in the left subtree (or minimum in the right subtree), copy its value to the node you want to delete, and then delete that original min/max node.

Tree Traversals

Traversal is the process of visiting all nodes in a tree exactly once. There are different strategies for this:

Breadth First (Level Order)

Visits nodes layer by layer, horizontally from top to bottom.

Output from diagram above:
40, 20, 100, 10, 25, 125

Depth First

  • Pre-order (Root, Left, Right):
    40, 20, 10, 25, 100, 125
  • In-order (Left, Root, Right):
    10, 20, 25, 40, 100, 125 (Yields Sorted Order!)
  • Post-order (Left, Right, Root):
    10, 25, 20, 125, 100, 40

Self-Balancing Trees & Heaps

If a BST is populated with sorted data (e.g., 1, 2, 3, 4), it becomes a straight line, losing its O(log N) speed and degrading to O(N). Self-balancing trees automatically rotate their structure to prevent this.

AVL Tree

Named after Adelson-Velsky and Landis (1962). It enforces a strict rule:

For EVERY node, the maximum height difference between its left and right subtree can be at most 1.

If it exceeds 1 during insertion/deletion, the tree performs structural rotations. Result: guaranteed O(log N) lookups, but slower insertions due to strict balancing.

Red-Black Tree

A less strict balancing act that requires fewer rotations, making insertions/deletions faster than AVL, though lookups might be slightly slower. Rules:

  • Every node is colored Red or Black.
  • The Root is always Black.
  • Red nodes CANNOT have Red children (must be Black).
  • Every path from a node to its empty leaf slots contains the exact same number of Black nodes.

Heap

A special complete binary tree, entirely focused on prioritizing the highest or lowest value at the root node. Useful for Priority Queues.

  • Max-Heap: Every parent node is strictly GREATER than or equal to its children. (Max at root)
  • Min-Heap: Every parent node is strictly LESSER than or equal to its children. (Min at root)
