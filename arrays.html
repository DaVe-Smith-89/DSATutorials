Arrays & Memory Management

The foundation of physical data structures and C++ memory mechanics.

1 C++ Pointers & Basics

Before diving into data structures, you must understand how memory is accessed in C++. Variables live in memory addresses, and pointers are special variables that store these addresses.

int a = 5;      // 'a' is a value type variable storing the integer 5
int* p;         // 'p' is a pointer that can hold the memory address of an integer
p = &a;         // The '&' operator gets the memory address of 'a'. Now p points to a
cout << *p;     // The '*' operator dereferences 'p', accessing the value 5
*p = 6;         // This directly changes the value in that memory address. Now a = 6

2 Arrays: The Contiguous Structure

An array is a physical, linear data structure that stores a fixed-size collection of elements of the same type in adjacent (contiguous) memory locations.

Advantages

Because elements are consecutive, if you know the index, the computer can instantly calculate the exact memory address. This means access time is O(1) (extremely fast).

Disadvantages

The size is fixed upon creation. Furthermore, inserting or deleting an element in the middle requires shifting all subsequent elements, which is slow (O(N)).

Under the hood, an array name is just a pointer to its first element:

int A[5] = {1, 2, 3, 6, 8};
A[0] = 12;      // Standard indexing
*A = 12;        // Exactly equivalent to A[0]
*(A+1) = 5;     // Pointer arithmetic: accesses A[1]

3 Stack vs Heap Memory

In C++, variables can be allocated in two different regions of RAM: the Stack or the Heap. Understanding the difference is vital for avoiding bugs.

Automatic

Stack Memory

Used for local variables (e.g., int a = 5;). It is highly organized and fast.

  • Very fast to allocate and access.
  • Memory is automatically freed when the function scope ends (no memory leaks).
  • Size is limited and fixed at compile time.
Manual

Heap Memory

Used for dynamic allocations (using the new keyword). It is a large pool of memory.

  • Can request massive amounts of memory at runtime.
  • Slower allocation.
  • NO garbage collection in C++. You must manually call delete or risk filling up your RAM!

Dynamic Arrays (Resizing)

Because standard arrays are fixed in size, if you need more space, you must use the Heap to create a new, larger array, copy the data over, and carefully delete the old array.

int* A = new int[5];                 // 1. Allocate initial array on the heap

int* temp = new int[10];             // 2. Create a bigger array when full
for(int i=0; i<5; i++) temp[i]=A[i]; // 3. Copy the existing data
delete[] A;                          // 4. CRITICAL: Free the old memory!
A = temp;                            // 5. Reassign pointer to the new array

4 2D Arrays

2D arrays are used to represent matrices or grids. They can also be created on the Stack or the Heap.

int A[2][3];                          
A[1][2] = 99;
