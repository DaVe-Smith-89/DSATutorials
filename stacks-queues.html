Stacks & Queues

Logical structures defining strictly controlled access patterns.

While Arrays and Linked Lists dictate how memory is organized physically, Stacks and Queues are Logical Data Structures (or Abstract Data Types). They dictate the rules of how data is added and removed, and they can be implemented under the hood using either an Array or a Linked List.

Stack: LIFO Principle

A Stack follows the Last In First Out (LIFO) principle. Imagine a stack of dinner plates: you add plates to the top, and you must remove plates from the top. You cannot easily grab a plate from the middle or the bottom.

Real-World Use Cases:

  • Undo/Redo mechanisms in text editors.
  • Browser History (the Back button).
  • Function Call Stack (how the OS tracks which function to return to).
  • Backtracking algorithms (like solving a maze).

Stack Implementation (Array-based)

When using an array, we track a top index that tells us where the highest plate is located.

void push(int val) {
    if (top >= capacity) 
        cout << "Stack Overflow!";
    else { 
        data[top] = val; 
        top++; // Move top index up
    }
}

int pop() {
    if (top == 0) 
        return -1; // Stack Underflow!
    else { 
        top--; // Move top index down
        return data[top]; 
    }
}

Queue: FIFO Principle

A Queue follows the First In First Out (FIFO) principle. Think of a line of people at a grocery checkout: the first person to enter the line is the first person to be served and leave.

In a Queue, elements are always added to the Rear (Enqueue) and removed from the Front (Dequeue).

Real-World Use Cases:

  • Printer Task Spooling (first document sent is first printed).
  • Operating System Task Scheduling (handling background processes fairly).
  • Customer Support Call Centers (waiting in line).

Circular Queue Optimization

If we implement a Queue using a standard array, as we Enqueue and Dequeue, the Front and Rear pointers keep moving to the right. Eventually, they hit the end of the array, even if there is empty space at the beginning! We solve this using a Circular Array approach with the modulo operator %.

void enQueue(int val) {
    if (size == capacity) 
        cout << "Queue is full!";
    else {
        data[rear] = val;
        // Wrap around to index 0 if rear reaches capacity
        rear = (rear + 1) % capacity; 
        size++;
    }
}

int deQueue() {
    if (size == 0) 
        return -1; // Empty queue
    else {
        int temp = data[front];
        // Wrap around front pointer just like rear
        front = (front + 1) % capacity;
        size--;
        return temp;
    }
}
